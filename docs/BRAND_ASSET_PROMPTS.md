# Brand and Image Generation Prompts

Use these prompts with Midjourney, DALL·E, Firefly, Leonardo, Ideogram or another image model. Keep all generated assets consistent: premium, trustworthy, modern, education-technology, enterprise SaaS, Nigerian/African-friendly but globally polished.

## Logo Prompt

```txt
Create a premium SaaS logo for “Horizons”, a modern school management operating system. Symbol should combine a graduation cap, structured data grid, and protective shield concept. Style: minimal geometric vector, enterprise SaaS, trustworthy, modern, scalable, strong silhouette, works as app icon and wordmark. Colors: deep navy, electric blue, emerald green, white. No cartoon style, no 3D, no mockup, no gradients that reduce legibility. Output clean vector-style logo on transparent background.
```

## Image Usage Rules

- Avoid fake screenshots with unreadable or incorrect UI.
- Do not use images that imply features not yet available unless clearly conceptual.
- Prefer abstract product visuals over fake stock photography when trust is critical.
- Optimize all images before deployment.
- Use WebP or AVIF when possible.
