# Security Policy

Horizons handles sensitive school, student, parent and financial data. Security is a priority.

## Report a Vulnerability

Please report vulnerabilities privately through the maintainer's GitHub or LinkedIn profile instead of opening a public issue.

Maintainer:

- GitHub: https://github.com/basgenix4u
- LinkedIn: https://www.linkedin.com/in/abdulbasit-abdulalim-94a701354

## Secret Rules

Never commit:

- `.env` files
- Database URLs
- API keys
- Payment keys
- Auth secrets
- Admin credentials

Use `.env.example` for safe placeholder values only.
